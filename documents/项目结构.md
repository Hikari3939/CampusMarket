# 项目结构

``` text
CampusMarket/
├── backend/                     # Flask 后端
│   ├── app/
│   │   ├── __init__.py          # Flask 应用工厂函数
│   │   ├── extensions.py        # 存放扩展 (db, jwt, cors, socketio)
│   │   ├── models.py            # SQLAlchemy ORM 模型 (User, Product, Order, Message, ProductImage, Favorite, Review)
│   │   ├── socket_events.py     # WebSocket 事件 (鉴权/收发消息/已读回执)
│   │   └── api/
│   │       ├── __init__.py
│   │       ├── auth.py          # 注册/登录（含密码强度校验，返回头像）
│   │       ├── product.py       # 商品 CRUD（多图上传、价格筛选、分类、分页、编辑）
│   │       ├── order.py         # 订单创建（行级锁）+ 取消（商品恢复）
│   │       ├── user.py          # 个人历史 + 资料/头像修改 + 密码修改 + 公开主页 + 评价查询
│   │       ├── message.py       # 联系人列表（含头像）+ 聊天历史
│   │       ├── favorite.py      # 收藏切换 + 收藏列表 + 批量状态查询
│   │       └── review.py        # 评价创建 + 已评价检查
│   ├── static/                  # 本地静态资源映射
│   │   └── uploads/             # 用户上传的商品图片
│   │       └── avatars/         # 用户上传的头像图片
│   ├── config.py                # 配置（从 .env 读取敏感信息）
│   ├── run.py                   # 项目启动入口（SocketIO + gevent）
│   ├── .env.example             # 环境变量模板
│   └── requirements.txt         # 依赖包列表
│
├── frontend/                    # Vue 3 前端
│   ├── public/
│   │   └── favicon.svg          # 网站图标
│   ├── .env.development         # 开发环境 API 地址
│   ├── .env.production          # 生产环境 API 地址
│   └── src/
│       ├── api/                 # 所有接口请求封装
│       │   ├── request.js       # Axios 拦截器 (Token 注入 + 401 处理 + 超时)
│       │   ├── auth.js          # 登录/注册
│       │   ├── product.js       # 商品 CRUD（多图上传 + 价格筛选 + 进度回调）
│       │   ├── order.js         # 订单创建 + 取消
│       │   ├── user.js          # 用户历史 + 资料/头像修改 + 密码修改 + 公开主页
│       │   ├── message.js       # 联系人 + 聊天历史
│       │   ├── favorite.js      # 收藏切换 + 收藏列表 + 批量状态检查
│       │   └── review.js        # 评价创建 + 已评价检查 + 评价列表
│       ├── stores/              # Pinia 全局状态
│       │   ├── user.js          # 用户登录态 + Token/头像管理
│       │   ├── chat.js          # WebSocket 连接 + 消息/联系人管理
│       │   └── theme.js         # 暗色模式切换 + localStorage 持久化
│       ├── router/
│       │   └── index.js         # 路由配置 + 导航守卫
│       ├── views/               # 页面级组件
│       │   ├── Home.vue         # 首页（分类+价格筛选 + 骨架屏 + 无限滚动 + 暗色切换）
│       │   ├── Login.vue        # 登录/注册双 Tab（含密码规则提示）
│       │   ├── ProductDetail.vue # 商品详情（多图轮播 + 收藏 + 购买/编辑/联系）
│       │   ├── Publish.vue      # 发布商品（最多5张图 + 分类选择 + 上传进度条）
│       │   ├── Profile.vue      # 个人中心（三 Tab + 头像上传 + 评价对话框 + 编辑资料）
│       │   ├── Chat.vue         # 聊天中心（联系人头像 + 对话框）
│       │   └── UserProfile.vue  # 用户公开主页（头像 + 信誉评分 + 评价列表）
│       ├── components/          # 可复用 UI 组件
│       │   ├── ProductCard.vue  # 商品卡片（收藏按钮 + 卖家迷你头像）
│       │   ├── ImageGallery.vue # 多图轮播组件（Gallery + 灯箱预览）
│       │   └── StarRating.vue   # 五星评分组件（交互/只读双态）
│       ├── App.vue              # 根组件（WebSocket 生命周期 + 多标签页同步）
│       ├── main.js              # 入口（注册 Pinia / Router / ElementPlus / 暗色 CSS）
│       └── style.css            # 全局主题（CSS 变量 + 暗色模式 + 东南大学 VIS 色彩）
│
├── documents/                   # 项目文档
│   ├── 项目文档.md              # 完整 API 文档 + 开发规范
│   ├── 项目结构.md              # 本文件
│   └── 开发流程.md              # 分阶段开发指南
│
├── mysql_init.sql               # 数据库初始化（建库 + 7 张表 + 索引）
├── seed_demo_data.py            # 演示数据填充脚本
└── Readme.md                    # 项目说明
```
