# 东南大学二手交易平台 - 开发文档

---

## 1. 技术栈概述

* **前端**：Vue 3 (Composition API) + Vite + Pinia (状态管理) + Vue Router + Element Plus (UI组件库) + Axios。
* **后端**：Python 3.10+ + Flask 3.x + Flask-SQLAlchemy (ORM) + Flask-JWT-Extended (鉴权) + PyMySQL。
* **数据库**：MySQL 8.0 (字符集 `utf8mb4`)。
* **架构**：前后端分离 (RESTful API JSON 交互)。
* **实时通讯**：`Flask-SocketIO` (后端，基于 `gevent` 异步并发) + `socket.io-client` (前端)。全局长连接维持，支持跨组件消息弹窗。

## 2. 全局设计规范

### 2.1 UI/UX 色彩规范 (基于东南大学 VIS)

前端全局样式已在 `src/style.css` 中定义为 CSS 变量，后续开发禁止使用硬编码颜色，统一使用以下变量：

* **标准主色**：
  * 东南绿: `var(--seu-green)` → `#587558` (用于系统主色调、主要按钮、激活状态)
  * 东南黄: `var(--seu-yellow)` → `#fdd000` (用于点缀、强调)
  * 标准黑: `var(--seu-black)` → `#231815` (用于深色背景、阴影)
* **标准辅助色**：
  * 活力橙: `var(--seu-orange)` → `#F6AB00` (用于价格文字、劝退操作)
  * 深邃蓝: `var(--seu-dark-blue)` → `#151E49` (用于大面积背景、Banner)
* **排版风格**：**现代扁平极简风**。去除不必要的边框，多留白，利用投影(`box-shadow`)区分层级。
* **暗色模式**：通过 `html.dark` 类名切换深色主题。所有颜色在 `style.css` 中通过 `html.dark` 选择器覆盖。Element Plus 组件通过导入 `element-plus/theme-chalk/dark/css-vars.css` 实现自动适配。主题偏好保存在 `localStorage`，刷新不丢失。

### 2.2 商品分类枚举

| 值 | 标签 |
| :--- | :--- |
| `textbook` | 教材教辅 |
| `electronics` | 电子数码 |
| `daily` | 生活日用 |
| `clothing` | 服饰鞋包 |
| `sports` | 运动户外 |
| `other` | 其他 |

### 2.3 后端 API 响应规范

所有接口的返回格式必须统一为 JSON。

* **成功响应 (HTTP 200/201)**：包含 `msg` (提示信息) 和可选的 `data` / `pagination` 字段。
* **分页响应**：列表接口在 `pagination` 字段返回 `{ total, page, per_page, pages }`。
* **失败响应 (HTTP 400/401/403/404/500)**：必须包含 `msg` 字段，前端 Axios 拦截器会**自动提取 `msg` 并通过 Element Plus 全局弹窗报错**。

## 3. 前端开发规范

### 3.1 目录职责划分

* `src/api/`: 所有后端接口必须在此目录下集中声明并导出，**严禁在 .vue 文件中直接写 axios.get(...)**。
* `src/stores/`: 全局状态管理。使用组合式 API 编写 Pinia store。含 `user.js`（用户状态）、`chat.js`（WebSocket）、`theme.js`（暗色模式）。
* `src/views/`: 页面级组件。
* `src/components/`: 可复用的颗粒化 UI 组件。含 `ProductCard.vue`、`ImageGallery.vue`（多图轮播）、`StarRating.vue`（五星评分）。

### 3.2 鉴权与路由拦截

* **Token 注入**：`src/api/request.js` 已配置请求拦截器。发起网络请求时，会自动携带 `Authorization: Bearer <token>`。
* **页面鉴权**：在 `src/router/index.js` 中，需登录页面必须添加 `meta: { requiresAuth: true }`。

### 3.3 环境变量

* 前端通过 `.env.development` / `.env.production` 配置 API 地址。
* `VITE_API_BASE_URL`：REST API 基础地址
* `VITE_WS_BASE_URL`：WebSocket 基础地址（不设置则回退到 `VITE_API_BASE_URL`）

## 4. 后端开发规范

### 4.1 目录职责划分

采用**应用工厂模式 (Application Factory)** 防止循环引用。

* `app/models.py`: 数据库 ORM 映射。所有 SQL 操作必须通过 SQLAlchemy 执行。
* `app/api/`: API 蓝图 (Blueprints) 目录。按业务划分文件。
* `app/extensions.py`: 存放实例化的第三方扩展。
* `config.py`: 集中管理配置，所有敏感值从 `.env` 环境变量读取。

### 4.2 数据库操作规范 (ORM)

* 所有涉及写入、更新、删除的操作，必须使用 `try...except` 包裹，并在 `except` 中执行 `db.session.rollback()`。
* 使用 `with_for_update()` 行级锁防止并发冲突。生产环境禁止 `str(e)` 返回给客户端。

### 4.3 图片上传规范

* 商品图片和用户头像均上传至 `static/uploads/`，文件名使用 `uuid.uuid4().hex + 扩展名`。
* **单图模式（旧）**：单字段 `image`。**多图模式（新）**：字段 `image_0`~`image_4`，最多 5 张，存储于 `product_images` 表。
* 编辑商品更换图片时，需先删除旧图片文件和数据库记录。
* 用户头像更换时删除旧头像文件。
* 前端通过 `onUploadProgress` 实时展示进度。

### 4.4 软删除规范

* 商品删除采用逻辑删除：`status` 改为 `'deleted'`。
* 已下架商品不可编辑，不出现在公开列表和搜索结果中。

## 5. API 接口文档

### 5.1 用户注册

* **路径**：`POST /api/auth/register`
* **权限**：公开访问
* **请求 Body (JSON)**：

    ```json
    { "username": "SEU小明", "email": "xiaoming@seu.edu.cn", "password": "your_password" }
    ```

* **密码规则**：至少 6 位，需同时包含字母和数字
* **成功响应 (201)**：`{ "msg": "注册成功" }`
* **失败响应 (400)**：`{ "msg": "密码长度不能少于6位" }` / `{ "msg": "该邮箱或用户名已被注册" }`

### 5.2 用户登录

* **路径**：`POST /api/auth/login`
* **权限**：公开访问
* **请求 Body (JSON)**：

    ```json
    { "email": "xiaoming@seu.edu.cn", "password": "your_password" }
    ```

* **成功响应 (200)**：

    ```json
    { "msg": "登录成功", "token": "eyJ...", "user": { "id": 1, "username": "SEU小明", "email": "xiaoming@seu.edu.cn" } }
    ```

* **失败响应 (401)**：`{ "msg": "邮箱或密码错误" }`（统一错误，防止用户枚举）

### 5.3 发布商品

* **路径**：`POST /api/products`
* **权限**：需 Header 携带 Token
* **Content-Type**：`multipart/form-data`
* **请求参数 (FormData)**：
  * `title` (String, 必填) — 商品标题
  * `price` (Numeric, 必填) — 商品价格 (>0)
  * `category` (String, 必填) — 分类，取值为 `textbook | electronics | daily | clothing | sports | other`
  * `description` (String, 可选) — 商品描述
  * `image` (File, 可选) — 单张图片（向后兼容），支持 png/jpg/jpeg/gif
  * `image_0` ~ `image_4` (File, 可选) — 多张图片（最多 5 张，按序号排序）
* **成功响应 (201)**：

    ```json
    {
      "msg": "商品发布成功",
      "data": {
        "id": 10,
        "seller_name": "SEU小明",
        "seller_avatar_url": "http://...",
        "title": "二手高数教材",
        "category": "textbook",
        "price": 15.50,
        "image_url": "http://...",
        "image_urls": ["http://...", "http://..."],
        "status": "active",
        "created_at": "2026-06-03 10:00:00"
      }
    }
    ```

### 5.4 获取商品列表（支持分类筛选 + 价格区间 + 分页）

* **路径**：`GET /api/products`
* **权限**：公开访问
* **Query Params**：
  * `keyword` — 标题模糊搜索
  * `category` — 分类筛选
  * `min_price` — 最低价格（可选）
  * `max_price` — 最高价格（可选）
  * `page` — 页码（默认 1）
  * `per_page` — 每页数量（默认 12，最大 48）
* **成功响应 (200)**：

    ```json
    {
      "msg": "获取成功",
      "data": [{ "id": 10, "title": "二手高数教材", "category": "textbook", "price": 15.50, "seller_avatar_url": "...", "image_urls": [...], ... }],
      "pagination": { "total": 100, "page": 1, "per_page": 12, "pages": 9 }
    }
    ```

### 5.5 获取商品详情

* **路径**：`GET /api/products/<id>`
* **权限**：公开访问
* **成功响应 (200)**：返回单个商品完整数据
* **失败响应 (404)**：`{ "msg": "商品不存在或已被删除" }` / `{ "msg": "该商品已下架" }`

### 5.6 编辑商品

* **路径**：`PUT /api/products/<id>`
* **权限**：需登录，**且操作者必须是卖家**
* **Content-Type**：`multipart/form-data`
* **请求参数 (FormData)**：同发布接口，所有字段均为可选（只更新传入的字段）。若传入 `image_0..image_4` 则删除所有旧图并替换为新图。
* **成功响应 (200)**：`{ "msg": "商品更新成功", "data": { ... } }`
* **失败响应**：403 越权 / 400 已下架商品不可编辑

### 5.7 删除商品（软删除）

* **路径**：`DELETE /api/products/<id>`
* **权限**：需登录，**且操作者必须是卖家**
* **成功响应 (200)**：`{ "msg": "商品删除成功" }`
* **失败响应 (403)**：`{ "msg": "无权操作他人的商品" }`

### 5.8 创建订单（购买）

* **路径**：`POST /api/orders`
* **权限**：需登录
* **请求 Body (JSON)**：`{ "product_id": 10 }`
* **成功响应 (201)**：`{ "msg": "购买成功", "data": { "order_id": 1, "order_no": "20260603123000A1B2C3D4", "deal_price": 15.50 } }`
* **失败响应 (400)**：`{ "msg": "手慢了，该商品已被抢购" }` / `{ "msg": "不能购买自己发布的商品" }`

### 5.9 取消订单

* **路径**：`PUT /api/orders/<id>/cancel`
* **权限**：需登录，**仅买家可操作**
* **成功响应 (200)**：`{ "msg": "订单已取消，商品已重新上架" }`
* **失败响应**：403 越权 / 400 订单已取消或状态不允许

### 5.10 我发布的商品

* **路径**：`GET /api/users/me/published`
* **权限**：需登录
* **成功响应 (200)**：`{ "msg": "获取发布历史成功", "data": [{ "id": 10, "title": "...", "category": "...", "price": 15.50, "status": "sold", ... }] }`

### 5.11 我购买的订单

* **路径**：`GET /api/users/me/bought`
* **权限**：需登录
* **成功响应 (200)**：`{ "msg": "获取购买历史成功", "data": [{ "order_id": 1, "order_no": "...", "deal_price": 15.50, "order_status": "completed", "product": { "id": 10, "title": "...", "seller_name": "SEU小明" }, ... }] }`

### 5.12 修改个人资料（用户名 + 头像）

* **路径**：`PUT /api/users/me`
* **权限**：需登录
* **请求方式**：
  * **JSON**：`{ "username": "新用户名" }` — 纯文本修改
  * **FormData**：`username` + `avatar` (File) — 同时修改用户名和头像
* **成功响应 (200)**：`{ "msg": "资料更新成功", "data": { "id": 1, "username": "新用户名", "email": "...", "avatar_url": "http://..." } }`
* **失败响应 (400)**：`{ "msg": "该用户名已被使用" }`

### 5.13 修改密码

* **路径**：`PUT /api/users/me/password`
* **权限**：需登录
* **请求 Body (JSON)**：`{ "old_password": "旧密码", "new_password": "新密码" }`
* **密码规则**：同注册（至少6位 + 字母 + 数字）
* **成功响应 (200)**：`{ "msg": "密码修改成功" }`
* **失败响应 (400)**：`{ "msg": "旧密码不正确" }`

### 5.14 用户公开主页

* **路径**：`GET /api/users/<id>/profile`
* **权限**：公开访问
* **成功响应 (200)**：

    ```json
    {
      "msg": "获取成功",
      "data": {
        "user": {
          "id": 2,
          "username": "SEU小明",
          "avatar_url": "http://...",
          "created_at": "2026-06-01 10:00:00",
          "avg_rating": 4.5,
          "review_count": 3
        },
        "products": [ ... ]  // 仅含 status=active 的商品
      }
    }
    ```

### 5.15 获取用户评价列表

* **路径**：`GET /api/users/<id>/reviews`
* **权限**：公开访问
* **成功响应 (200)**：

    ```json
    {
      "msg": "获取成功",
      "data": {
        "reviews": [
          {
            "id": 1,
            "order_id": 5,
            "reviewer": { "id": 3, "username": "SEU小明", "avatar_url": "..." },
            "rating": 5,
            "comment": "卖家很爽快，商品成色很好！",
            "created_at": "2026-06-03 12:00:00"
          }
        ],
        "avg_rating": 4.5,
        "review_count": 3
      }
    }
    ```

### 5.16 创建交易评价

* **路径**：`POST /api/reviews`
* **权限**：需登录（评价者必须是订单的买家或卖家，且每人对同一订单只能评价一次）
* **请求 Body (JSON)**：

    ```json
    { "order_id": 5, "rating": 5, "comment": "卖家态度很好！" }
    ```

* **评分规则**：`rating` 为 1-5 的整数
* **成功响应 (201)**：`{ "msg": "评价成功", "data": { "id": 1, "rating": 5, "comment": "...", "created_at": "..." } }`
* **失败响应 (400)**：`{ "msg": "您已经评价过该订单了" }` / `{ "msg": "只能评价已完成的订单" }`

### 5.17 检查是否已评价

* **路径**：`GET /api/reviews/check/<order_id>`
* **权限**：需登录
* **成功响应 (200)**：`{ "data": { "reviewed": true } }` 或 `{ "data": { "reviewed": false } }`

### 5.18 收藏/取消收藏

* **路径**：`POST /api/favorites`
* **权限**：需登录
* **请求 Body (JSON)**：`{ "product_id": 10 }`
* **功能**：切换式操作 — 已收藏则取消，未收藏则添加
* **成功响应**：
  * 收藏 (201)：`{ "msg": "收藏成功", "data": { "is_favorited": true } }`
  * 取消 (200)：`{ "msg": "已取消收藏", "data": { "is_favorited": false } }`

### 5.19 获取收藏列表

* **路径**：`GET /api/favorites?page=1&per_page=12`
* **权限**：需登录
* **成功响应 (200)**：返回分页的商品列表（仅含在售商品），每项附带 `favorited_at` 收藏时间

### 5.20 批量检查收藏状态

* **路径**：`GET /api/favorites/check?ids=1,2,3`
* **权限**：需登录
* **成功响应 (200)**：`{ "data": [1, 3] }` — 返回已收藏的商品 ID 列表

### 5.21 获取联系人列表

* **路径**：`GET /api/messages/contacts`
* **权限**：需登录
* **成功响应 (200)**：返回按最后聊天时间倒序的联系人，含头像、未读计数

### 5.22 获取聊天历史

* **路径**：`GET /api/messages/history/<contact_id>`
* **权限**：需登录
* **成功响应 (200)**：返回对话记录（联系人含头像），并自动将对方发来的未读消息标记为已读

## 6. 实时通讯 WebSocket 规范

### 6.1 鉴权与连接生命周期

* **全局连接**：前端在 `App.vue` 中监听 Token 变化。登录自动连接 WebSocket，退出自动断开。
* **握手鉴权**：客户端连接时传递 `auth: { token: "<JWT>" }`，后端通过 `decode_token` 解析。
* **多标签页同步**：`storage` 事件监听，跨标签页登录切换时自动刷新对齐。

### 6.2 Socket 核心事件

| 事件 | 方向 | 载荷 | 说明 |
| :--- | :--- | :--- | :--- |
| `send_message` | 前端 → 后端 | `{ "receiver_id": 2, "content": "你好" }` | 发送私信，后端持久化并路由推送到接收方 |
| `receive_message` | 后端 → 前端 | `{ "id": 102, "sender_id": 1, "content": "你好", ... }` | 推送新消息；不在当前聊天窗口则全局通知 |
| `message_sent` | 后端 → 前端 | `{ "id": 102, ... }` | 发送方收到确认，用于替换本地临时消息 |
| `mark_as_read` | 前端 → 后端 | `{ "message_id": 102 }` | 已读回执，消除幽灵未读 |
| `error` | 后端 → 前端 | `{ "msg": "..." }` | 异常统一回抛 |
